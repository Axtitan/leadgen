      TomTom key (free)

      Finds far more businesses than OpenStreetMap, with phones and websites, and needs no card. About 2,500 searches a month free; when they run out, searches stop until next month and nothing is charged.

      1. Create a free account at developer.tomtom.com.
      2. In your Dashboard, open the key and make sure Search API is ticked.
      3. Paste the key below.

      Google key (optional, paid past the free amount)

      Google adds ratings and review counts, which helps pick the busiest businesses. It needs a billing account. Enable Places API (New), plus PageSpeed Insights API for speed tests.
